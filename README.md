# Виталий Кутузов — персональный сайт

Локальное портфолио на React + TypeScript + Vite. Главная, отдельные страницы кейсов, интерактивный пример граничных значений, адаптивная компоновка и шесть эффектов без дополнительных библиотек анимации. Публикация настроена через GitHub Pages.

## Быстрый запуск в Windows

Дважды нажмите **Открыть сайт.cmd** в этой папке, дождитесь сообщения Vite и откройте **http://127.0.0.1:5173/** в браузере. Скрипт использует установленный pnpm либо поставляемый с Codex runtime. При отсутствии `node_modules` установит зависимости. Окно запуска должно оставаться открытым; Ctrl+C останавливает сервер. Если порт 5173 уже занят ранее запущенным экземпляром этого портфолио, используйте уже открытый адрес.

Кейс Starfood: **http://127.0.0.1:5173/projects/starfood/**.

## Команды

Требования для обычного терминала: Node.js 22.13+ и pnpm. Доступен также npm: `npm install`, `npm run dev`, `npm run build`, `npm run preview`. В проекте сохранён `pnpm-lock.yaml`, поэтому для воспроизводимой установки предпочтителен pnpm.

```powershell
pnpm install
pnpm dev
```

Сборка:

```powershell
pnpm build
```

Команда выполняет только компиляцию TypeScript, сборку Vite и создание статических HTML-точек входа для кейсов. Тестовые команды и хуки отсутствуют.

Просмотр готовой сборки:

```powershell
pnpm preview
```

Адрес готовой сборки: **http://127.0.0.1:4173/**. Открывать `dist/index.html` двойным щелчком через `file://` не нужно: ES-модулям нужен локальный HTTP-сервер. Dev-сервер и preview привязаны только к `127.0.0.1`.

## Где менять содержимое

### Контакты, фото и обучение

Файл **`src/data/profile.ts`**:

- `profile.name`, `initials`, `bio` — данные профиля;
- `profile.photo` — путь к фото в `public`, например `/images/vitaly.jpg`;
- `profile.contacts.email` — email без `mailto:`;
- `profile.contacts.telegram` — полная ссылка `https://t.me/...`; `telegramLabel` — отображаемое имя;
- `profile.contacts.phone` — номер для ссылки `tel:`, `phoneLabel` — номер в читаемом формате;
- `profile.contacts.resume` — ссылка или путь к PDF резюме;
- `profile.education.document` — путь к документу, например `/documents/skillbox.pdf`;
- `skills` — карточки практических примеров;
- `dossierSkills` — HARD SKILLS и SOFT SKILLS: каждое поле `label` используется в компактном списке, а `details` — в раскрываемых пояснениях;
- `directions` — предложения для заказчиков и работодателей.

Скопируйте собственное фото в `public/images`, документ в `public/documents` (создайте папку при необходимости) и укажите пути в данных. Для фото, резюме и документа обучения `null` означает отсутствие материала. Контакты уже заполнены: почта, Telegram и телефон отображаются с подписями и настоящими ссылками. Формы отправки нет.

### Как добавить проект

Основной файл — **`src/data/projects.json`**. Добавьте объект по структуре Starfood, используя уникальный `slug` из строчных латинских букв, цифр и одиночных дефисов. Например, `my-project` создаст адрес `/projects/my-project/`.

- `title`, `category`, `summary`, `tags`, `stack` — карточка проекта;
- `cover` — путь к реальному изображению в `public/images`;
- `task`, `role` — задача и роль;
- `features`, `architecture`, `qa` — разделы кейса;
- `qaNote` — ограничения известных результатов, при наличии;
- `gallery` — массив реальных скриншотов: `src`, `alt`, `caption`, необязательное `note`;
- `url` — внешний сайт, необязательно;
- `materials` — доступные материалы: `title`, `url`, `download`, необязательно.

Типы полей описаны в `src/data/projects.ts`. Галерея без изображений покажет заглушку. Проекты и маршруты формируются из данных, новые React-компоненты не нужны. После изменения данных повторите `pnpm build`, чтобы создать соответствующие статические точки входа.

## Внешний вид и движение

**`src/styles/tokens.css`** — общие цвета, шрифты, ширина содержимого, скругления и длительности. **`src/styles/main.css`** — базовые компоненты и адаптивные правила. **`src/styles/identity.css`** — нейтральное чёрное оформление, типографика имени, цифровое досье, открытая композиция разделов и фоновые слои. Максимальная ширина содержимого — 1400 px.

**`src/config/motion.ts`** — общий выключатель `enabled`, отдельные переключатели `spotlight`, `tilt`, `targetCursor`, `decrypt`, `reveal`, `background`, максимальный наклон `maxTilt` и длительность расшифровки `decryptDuration`.

Реализованы:

1. Target Cursor — уголки прицела только внутри QA-блока для мыши. Обычный курсор сохранён; декоративный слой не перехватывает клики.
2. Spotlight Card — мягкое свечение внутри карточек за мышью.
3. Tilted Card — наклон профиля до 4° по каждой оси с возвратом.
4. Carousel — архивные снимки в кейсе, без автопрокрутки. Кнопки, индикаторы, свайп, клавиши ←/→, Home/End при фокусе на изображении. Вертикальная прокрутка и масштабирование жестом сохранены.
5. Decrypted Text — короткая анимация только технической подписи первого экрана. Доступное имя остаётся стабильным.
6. Animated Content — однократное появление разделов при пересечении видимой области. Контент не скрывается в ожидании анимации.

Дополнительно есть тонкие светящиеся линии и техническая сетка фона. Фон фиксирован, обрезан по экрану и не принимает события указателя. `prefers-reduced-motion` отключает движение и эффекты указателя. Стандартная прокрутка браузера не заменена.

### Фон, связанный с прокруткой

`Background` в `src/components/Effects.tsx` содержит три слоя: дальнюю сетку с линией, среднюю линию и ближнюю дугу; у каждого свои технические маркеры. Положение прокрутки, выраженное в высотах окна, определяет смещение X/Y и угол поворота слоя. Ограниченные синусоидальные траектории оставляют линии в области экрана даже на длинных кейсах. Возврат к прежней позиции страницы возвращает декор в прежнее положение.

Параметры `src/config/motion.ts`:

- `parallaxSpeeds: [0.32, 0.65, 1.05]` — скорости прохождения траекторий трёх слоёв;
- `scrollSmoothingMs: 85` — постоянная времени сглаживания; около 95% реакции за 255 мс;
- `mobileParallaxScale: 0.4` — 40% амплитуды на ширине до 760 px; третий слой и сетка скрыты;
- `background: false` или `enabled: false` — статичный фон.

Базовые амплитуды: по Y — 24% высоты окна, по X — 95 px, поворот — 9°, 14° и 19° для соответствующих слоёв. Скролл слушается пассивно; `requestAnimationFrame` пишет только `transform` декоративных элементов и прекращает работу после достижения цели. React-состояние на прокрутке не обновляется. При скрытии вкладки цикл останавливается, при изменении reduced-motion обработчики удаляются и трансформации сбрасываются. Самостоятельного движения по таймеру нет.

Порядок слоёв задан явно: фон — `z-index: 0`, содержимое — `z-index: 1` внутри изолированного корня. Общие секции прозрачны; локальное затемнение используется под текстом и интерактивными панелями. Движение фона не меняет положение текста и кнопок.

Кейс и галерея загружаются отдельным модулем только при переходе на страницу проекта. Тяжёлых WebGL/анимационных зависимостей нет. Шрифт с кириллицей включён локально.

## QA-демонстрация

`src/components/QADemo.tsx` — учебный расчёт для 599, 600 и 601 ₽. Бесплатная доставка от 600 ₽, ниже — 150 ₽. Переключатель искусственной ошибки заменяет `>=` на `>`; интерфейс явно поясняет происхождение примера. Демонстрация не обращается к Starfood и не запускает тесты.

## Структура

```text
src/
  components/       общие компоненты, эффекты, QA и галерея
  config/motion.ts  параметры движения
  data/             профиль, навыки, направления и проекты
  pages/            главная и общий шаблон кейса
  styles/           токены и адаптивное оформление
public/
  images/           три безопасных архивных скриншота
  materials/        публичный QA-разбор
scripts/            статические точки входа кейсов и локальный запуск
docs/materials.md   происхождение материалов и ограничения
```

`dist` предназначен для статического HTTP-хостинга в корне домена. `/projects/<slug>/index.html` создаётся при сборке, чтобы прямые ссылки на кейсы не зависели от SPA fallback. Непредусмотренные адреса отображают экран «Страница не найдена», если хостинг отдаёт `404.html` или SPA fallback. Настройка HTTP-статуса 404 остаётся задачей будущего хостинга. Публикация выполняется через GitHub Actions.

## Материалы и границы достоверности

Figma недоступна из-за лимита MCP Starter. Визуальная основа — подробное задание и просмотренные кадры записи референса. Подробности источников: `docs/materials.md`.

Starfood находится в отдельной папке на рабочем столе и использован только для чтения. Перенесены только три просмотренных снимка публичных страниц; опубликованных исходников Starfood, конфигураций, клиентских данных, заказов и браузерных профилей здесь нет. В галерее отмечены архивность и неполная иллюстрация на снимке доставки.

По предоставленным владельцем данным, прежний локальный запуск восьми тестов доставки прошёл успешно. Его не повторяли; он не подтверждает исправность всего Starfood и не является результатом проверки портфолио.

**Тестирование портфолио не проводилось по указанию пользователя.** Тесты, Playwright/Cypress, браузерные и скриншотные проверки, Lighthouse и автоматические аудиты не создавались и не запускались. На этом этапе разрешена только сборка компиляции.

## Дополнение: досье и читаемость

В `src/styles/identity.css` локальные радиальные маски затемняют фон вокруг текстовых областей, сохраняя прозрачные переходы и свободные промежутки. Ведущая линия — `.orbit-1` среднего слоя; остальные дуги приглушены. Параллакс и параметры сглаживания сохранены.

Сканирующая линия `.profile-photo::after` проходит за 3,5 секунды и остаётся невидимой следующие 5 секунд. Эффект действует и на заглушке, и после заполнения `profile.photo`, ограничен рамкой фотографии. Индикатор рядом со статусом «Готов к сотрудничеству» пульсирует раз в 3 секунды, не исчезая; это не онлайн-статус. При reduced-motion или общем отключении анимаций полоса скрывается, точка остаётся статичной.

HARD SKILLS и SOFT SKILLS находятся в продолжении личного дела под первым экраном; пояснения раскрываются через нативный `details/summary` нажатием, Enter или пробелом. Служебное сообщение о прежнем запуске восьми тестов удалено из данных кейса Starfood, а описания QA-практики сохранены.

Фото профиля подключено из `public/images/vitaly-profile.png` (исходник — `Фото визитка.png`). Положение в рамке задаёт `.profile-photo img` в `src/styles/identity.css`; сканирующая линия сохранена. Сертификат Skillbox подключён из `public/images/skillbox-certificate.jpg`. Оставшийся незаполненный материал: резюме. Контакты и ссылка на GitHub заполнены.

## GitHub Pages

Workflow `.github/workflows/pages.yml` устанавливает зависимости по lockfile, собирает и публикует `dist` после push в `main`. Сборка не запускает тестов. Для публикации используется `VITE_BASE_PATH=/vitaly-kutuzov-portfolio/`; локальная разработка сохраняет `/`. Внутренние ссылки и изображения обрабатываются через `src/config/urls.ts`. Статические страницы кейсов создаются при сборке.

Для другого имени репозитория измените `VITE_BASE_PATH` в workflow. При собственном домене используйте `/`. В Settings → Pages источником должен быть GitHub Actions.

В публичный репозиторий не включены `qa-assignment`, локальные сборки, зависимости, логи, файлы окружения и дубликат исходного фото в корне. Рабочее фото включено в `public/images`.

## Сертификат и GitHub

Ссылка на GitHub задаётся в `profile.contacts.github` и отображается в контактах с иконкой; открывается в новой вкладке с `noopener noreferrer`. Данные курса, номер, дата и путь к изображению хранятся в `profile.education`. Компонент `EducationCertificate` находится в разделе «Обо мне» после навыков. Превью открывает нативный HTML dialog; предусмотрены закрытие кнопкой, Escape и нажатием на затемнённый фон, а также отдельная ссылка на изображение в полном размере. Дополнительные зависимости не установлены.
